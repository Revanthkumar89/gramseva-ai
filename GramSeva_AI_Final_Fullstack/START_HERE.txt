GRAMSEVA AI FINAL PROJECT

1. Install Node.js 20+ and PostgreSQL.
2. In PostgreSQL run: CREATE DATABASE gramseva_ai;
3. cd backend
4. Copy .env.example to .env and set DATABASE_URL with your password.
5. npm install
6. npx prisma generate
7. npx prisma migrate dev --name init
8. npm run seed
9. npm run create-admin -- "Admin Name" 9876543210 Password123
10. npm run dev
11. In another terminal: cd frontend
12. npx serve -l 5500
13. Open http://localhost:5500

The frontend and backend are included together. PostgreSQL stores the real data.
